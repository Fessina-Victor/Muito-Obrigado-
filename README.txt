# WebAR — Muito Obrigado

Projeto gratuito de Realidade Aumentada usando MindAR + A-Frame.

## Fluxo
QR Code → página WebAR → câmera → reconhecimento da imagem → robô holográfico + “MUITO OBRIGADO!”

## O que falta fazer
1. Abra o compilador oficial de Image Targets do MindAR:
   https://hiukim.github.io/mind-ar-js-doc/tools/compile/
2. Envie a imagem `marcador_webAR.png`.
3. Gere e baixe `targets.mind`.
4. Coloque `targets.mind` na mesma pasta de `index.html`.
5. Publique os arquivos em um repositório público no GitHub.
6. Ative GitHub Pages.
7. O endereço final do GitHub Pages será usado para gerar o QR Code.

## Observação
O arquivo HTML já contém o robô holográfico construído com primitivas A-Frame, portanto não depende de um modelo 3D externo.
